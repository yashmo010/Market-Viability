# Root Cause Analysis: Mock Bridge Fallback in Historical Baseline

## 1. Finding & Phenomenon
An inspection of `Capstone updated/Capstone/src/strict_temporal/predict_test.py` and benchmark cache files `models/benchmarks/*.jsonl` revealed that out of 124 strictly launch-blind temporal test products:
- Only **26 products** possessed pre-cached LLM aspect scores generated by `prompt_v2`.
- The remaining **98 products** fell back to `_mock_bridge(item, category)`.

## 2. Mechanistic Analysis of `_mock_bridge`
When a product lacked a cached prompt output, `StrictPredictor` computed:
```python
def _mock_bridge(self, spec: dict, category: str) -> dict[str, float]:
    prof = self.profiles[category]
    median_price = prof["price"]["median"] or 1.0
    price = float(spec.get("price", median_price))
    nudge = max(-1.5, min(1.5, (median_price - price) / max(median_price, 1.0) * 2.0))
    scores = {}
    for a in PHYSICAL_ASPECT_KEYS:
        base = prof["avg_aspect_scores"].get(a, 5.0)
        val = max(0.0, min(10.0, base + (nudge if a == "value_for_money" else nudge * 0.3)))
        scores[a] = round(float(val), 2)
    return scores
```
- For all 98 items, the 9 aspect scores were assigned the **category average aspect scores** plus a small scalar nudge proportional to price deviation from the category median.
- This effectively eliminated product-specific specification variance for 79.0% of the test cohort, reducing the aspect bridge to a category prior plus price heuristic.

## 3. Scientific Impact & Fairness Requirement
- Per Section 9 of the Final Audit Master Protocol, a new model must **NOT** claim superiority solely because the baseline was degraded by missing inference outputs.
- We establish two baseline standards:
  1. **BASELINE-H (Historical Reproduction)**: Exactly reproduces the historical `StrictPredictor` pipeline ($\rho = 0.5621$, $\text{AUC} = 0.8899$).
  2. **BASELINE-C (Controlled Canonical Model_O)**: Re-trained on 507 training items using the identical canonical feature set (9 aspects, price, brand tier, category, mention rates) under the same information boundary without specification density.
- We decompose the delta into:
  - $\Delta_{\text{mock}}$: The effect of the mock bridge fallback.
  - $\Delta_{\text{representation}}$: The genuine contribution of the enriched cold-start representation (Candidate B vs Controlled Baseline).
